## Correção de erros
O código original apresentava falhas em verificação de condições e permanência de dados em sessões.

Para a resolução foi adicionado um modelo de verificação adequado com o operador de igualdade (==); quanto a permanência dos dados, foi incluso na sessão do usuário o status da aplicação, logo, um header location seguido de um exit.

Nos primeiros minutos, imaginei que poderia ser erro de sintaxe na declaração de classes CSS, porém, logo percebi que as mesmas estavam corretas. Adiante, com uma leitura de código mais atenta, os erros foram percebidos e rapidamente corrigidos.
