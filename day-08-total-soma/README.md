## Correção de Erros

O código tem como objetivo somar os valores de pedidos por cliente, ordenar do maior para o menor e exibir os dois que mais gastaram.

Na versão com erro, o valor total de cada cliente era sobrescrito a cada iteração, fazendo com que apenas o último pedido fosse considerado. Isso comprometia o resultado final da ordenação.

Na versão corrigida, foi utilizado o operador de soma acumulativa, garantindo que todos os pedidos de cada cliente sejam somados corretamente e que o resultado final esteja de acordo com o esperado.
