## Projeto do Dia

Projeto simples desenvolvido como parte de uma rotina de prática diária em desenvolvimento web.

A proposta não é complexidade, mas sim consistência.
Tempo: 20 min.

### Funcionalidades

Aumentar o valor;
Diminuir o valor;
Multiplicar por 2;
Dividir por 2 (quando diferente de 0).
Resetar o contador

### Mudança de cor dinâmica:

Verde quando: número positivo;
Vermelho quando: número negativo;
Preto quando: número zero.
