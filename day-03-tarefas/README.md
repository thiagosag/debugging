## Correção de erros

Este projeto começou como um sistema de lista de tarefas propositalmente quebrado, com múltiplos erros de lógica, estrutura e integração entre PHP, HTML, CSS e JavaScript.

A versão inicial apresentava problemas críticos como manipulação incorreta de `$_SESSION`, erros na verificação de dados do formulário, falhas no controle de estado das tarefas e cálculos inconsistentes de progresso. Além disso, havia problemas de lógica em loops, uso incorreto de operadores e ausência de validações básicas, o que comprometia o funcionamento geral da aplicação.

Na versão corrigida, o fluxo de dados foi estabilizado, com validações adequadas nos inputs, correção do gerenciamento de sessão e ajustes na lógica de adição, remoção e conclusão de tarefas. O cálculo de progresso também foi reestruturado para refletir corretamente o estado atual da lista, além de melhorias na estrutura geral do código para garantir consistência e previsibilidade no comportamento do sistema.
